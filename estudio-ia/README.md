# Estudio IA

Clon funcional inspirado en Higgsfield: generación de imágenes, video (con presets de movimiento de cámara) y edición de imágenes con IA.

Uso: abre `index.html` en el navegador, pega tu clave API de [fal.ai](https://fal.ai) (se guarda solo en tu navegador), escribe un prompt y pulsa **Generar**.

Pestañas: **Imagen** (FLUX, Recraft), **Video** (Kling, MiniMax; texto o imagen a video), **Editar** (FLUX img2img / Kontext).
